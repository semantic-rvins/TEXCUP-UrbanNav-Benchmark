# SeA-RVINS result adapter

This adapter converts the supplied batch, latent and scalar
[SeA-RVINS](https://github.com/semantic-rvins/semantic-rvins.github.io) record archives
to the common ALT1 antenna trajectory format. See
[results/SeA-RVINS/README.md](../../results/SeA-RVINS/README.md) for Git LFS
retrieval, import commands, frame/time validation and provenance limits.

The original estimator has not been rerun from this benchmark checkout.
Its complete source/configuration manifests were not included in the supplied
archives. Conversion and statistics are reproducible from the versioned inputs.
